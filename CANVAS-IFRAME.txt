HOW TO USE
  Canvas page > Edit > the </> HTML editor button > paste > Save > PUBLISH.
  Heights are starting values. If a page runs long inside Canvas, raise the
  number; if it leaves white space, trim it. Canvas strips scripts, so the
  fixed height is what Canvas uses.

WHAT CHANGED IN THIS VERSION
  course-door gained the This Week card, so its height went up.
  The four doors now open their own term-wide index pages.
  assignment-notesheet and assignment-physioex were rebuilt lean, so their
  heights came way down.
  New pages: the four door indexes, the reference range lab, the fluid
  balance case, the enzyme lab, the Week 2 prompts, the vision board, and
  the 250 questions page.
