TBL Builder, competency driven

Pick the competencies the session has to move, and the readiness assurance test, the application activity and the timing are built around them. Competencies load live from your BIO 004 course repo, so this stays current when you edit them there. Every RAT item carries the competency it tests and links to the notes page that covers it.

3. Session settings

Building lays out the RAT slots and the 4S activity from what you ticked, spreading items across competencies and weighting core ahead of support. It does not invent anatomy. You write the stems, and each slot tells you exactly which competency and notes page it has to come from.

4. Readiness assurance test

Same items for iRAT and tRAT. The key letters were shuffled for you so the answers are not all sitting on B and C.

5. Application activity, 4S
