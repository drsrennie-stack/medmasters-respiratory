Lecture Writer

Start from your objectives and build the lecture around them. Each segment holds the teaching sequence, the figure you will show, the clinical connection, a retrieval check, and a drawing prompt. Print the plan or hand the outline to the slide builder.

1. Set up the lecture

The type code follows your naming pattern: A for anatomy, AL for anatomy lab, P for physiology.

One question or case that makes the day's material matter before you teach any of it.

2. Objectives

Write what students should be able to do by the end. Tag each one with its depth of knowledge level so you can see whether the lecture stays at recall.

3. Segments

Break the class into working blocks. The timing bar tells you when you have written more lecture than you have minutes.

0 of 75 minutes used

4. Save and export

Drafts save in this browser only. Nothing is uploaded anywhere. Use the file export to move a draft to another computer.
