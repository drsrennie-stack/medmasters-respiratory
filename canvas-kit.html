The Canvas assignment kit.

Everything needed to build a week's assignments in Canvas: pick the week, copy each embed into the assignment's HTML editor (the </> button), set the dates shown, publish. The pages relabel themselves by week; the snippets below already carry the right parameter.

Once, before Week 1: the five assignment groups

  1. In Canvas, Assignments, create five groups and turn on weight final grade by group: Competency note sheets 20%, Midterms 40%, Lab 15%, Book problems 15%, Discussions 10%.
  2. Point values inside a group can be anything consistent; the weights do the math. Ten points per weekly item is easy to read.
  3. Name every assignment the same way: Week 03 · Note sheet, so the list sorts itself.
  4. Worksheets are linked, never embedded. Anything students complete goes in as a link that opens in its own tab; they print it to PDF or copy it to paper, work by hand, and upload. Only directions pages get iframed.
  5. All due times are 10:00 pm. Discussions get two dates: initial post Friday, replies Sunday (use the Canvas available/due fields).
  6. Pearson items: assign the week's PhysioEx activities by name in Mastering, completion weight; the graded points live on the Canvas lab assignment. The week-by-week exercise list is in physioex-lab-map-fall2026.md.
